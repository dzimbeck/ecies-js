▶ Technical Specifications

Protocol: ECIES (Elliptic Curve Integrated Encryption Scheme)
Supported Curves: secp256k1, x25519
Supported Ciphers: AES-256-GCM, XChaCha20-Poly1305
KDF: HKDF-SHA256 over senderPoint ‖ sharedPoint (no salt)
Ciphertext Format: ephemeralPubKey ‖ nonce ‖ tag ‖ ciphertext
Compatibility: Wire-compatible with eciesjs

Note: ed25519 is available in eciesjs but not implemented here. Use x25519 for Curve25519 key exchange.
